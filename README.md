# 🧠 nextjs-AIChatbot

A modern ChatGPT-style AI assistant built with **Next.js 14** and **OpenAI API**.  
Uses **Material UI** and **Tailwind CSS** for a sleek, responsive interface that delivers real-time AI chat experiences.

![Preview](assets/preview.png) <!-- replace with your image path -->

## ✨ Features
- Real-time AI chat powered by OpenAI API
- Beautiful Material UI + Tailwind interface
- Server-side rendering with Next.js App Router
- Deployed on Vercel
